# Enigmatic Delicacy Legacy

**Minecraft Version:** 1.12.2 (Forge 14.23.5.2847)

An unofficial 1.12.2 port of **Enigmatic Delicacy** by **Auviotre**, originally made for NeoForge 1.21.1.
All original code, assets and designs belong to Auviotre. This project does not claim ownership of them.

**Changes from the original:**

- Rewritten for Forge 1.12.2 and Farmer's Delight Legacy; recipes are registered in code
- Enigmatic Legacy+ materials missing in 1.12.2 are provided by Enigmatic Addons Legacy or replaced with 1.12.2 equivalents
- The Voracious Pan is merged into Enigmatic Legacy's Eldritch Pan
- Fixed several bugs of the original
- Added compatibility with 1.12.2 mods

**Dependencies:**

- Enigmatic Legacy (legacy) 2.8.0 or later
- Enigmatic Addons Legacy 1.4 or later
- Farmer's Delight Legacy 1.1.7
- Baubles 1.5.2 or later
- FermiumBooter 1.2.0 or later

**Optional Mods:** JEI, Hwyla, CraftTweaker, SimpleDifficulty, Nether's Delight Legacy, BaubleVault, Trinkets and Baubles, Netherized, Ice and Fire, Bountiful Baubles, Deeper Depths, Raids Backport
